# Personal Portfolio Website

## Objective
A responsive personal portfolio website developed using Next.js.

## Technologies
- Next.js
- React
- JavaScript
- CSS Modules
- Next.js API Routes

## Features

### Home
- Hero section
- Personal introduction
- Navigation bar
- Background image

### About
- Profile picture
- Personal background
- Skills and interests

### Projects
- Project cards
- GitHub links
- Static generation using getStaticProps
- Local JSON data

### Contact
- Contact form
- API route for form submission
- Saves messages to a JSON file

### Responsive Design
- Mobile-friendly layout
- Tablet support
- Desktop support

## Routes
- /
- /about
- /projects
- /contact
- /api/contact

## Run Project

npm install
npm run dev

Open http://localhost:3000
